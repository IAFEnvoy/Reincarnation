# Reincarnation · 转生

[English](README.md)

**开启新的一世，留下前世的记录。**

在同一个 Minecraft 世界中重新开始：每次转生重置个人进度、进入下一世，并保存上一世的档案。已有的世界和建筑继续保留。

## 主要功能

- **重新开始：**重置背包、末影箱、经验、配方、进度和统计，初始从第 1 世开始。
- **回顾前世：**通过档案界面选择世代，查看时间、转生原因和玩家信息。
- **死亡后自动转生：**可选开启，也可以限制只有指定死因才触发转生。
- **可选寿元系统：**年龄随时间增长，寿元将尽时收到提醒，并可设置寿尽后的处理方式；离线不消耗寿元。

## 开始使用

| 指令                           | 用途                      |
|------------------------------|-------------------------|
| `/reincarnation view`        | 打开自己的当前世与前世档案。          |
| `/reincarnation history`     | 在聊天栏查看自己的世代记录。          |
| `/reincarnation view Alex 1` | 查看 Alex 的第 1 世，需要管理员权限。 |
| `/reincarnation rebirth @s`  | 为自己开启新的一世，需要管理员权限。      |
| `/lifespan get @s`           | 查询自己的寿元，需要管理员权限。        |

普通玩家可以查看自己的记录。查看他人记录、执行转生和管理寿元需要管理员权限（等级 2）。

## 按需配置

通过**模组列表 → Reincarnation → 配置**调整设置，修改服务端设置需要管理员权限。

- **死亡自动转生和自然老化默认关闭，**可按需开启。
- **死因筛选：**开启死亡自动转生后，可进一步限制触发死因。默认只允许寿元耗尽触发，其他死亡正常重生。
- **寿元规则：**开启老化后默认总寿元为 60 岁，年龄从零增长；剩余寿元不高于 10% 时提醒。初始寿元、老化速度和寿尽后的处理均可调整。
- **重置规则：**可选择是否保留游戏模式、队伍和记分板分数。

即使开启 `keepInventory`，转生仍会重置背包。其他模组的成长数据可能需要兼容支持。前世档案仅供查看，不能恢复为当前玩家。
